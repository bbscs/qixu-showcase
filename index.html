用你自己的 Agent定制栖序

无论你运行源码还是打包好的 EXE，都可以对 Codex、Claude Code 或其他能在本机执行命令的 Agent 描述你想要的桌宠。人设、聊天模型、窗口和勿扰时段都能请它代你设置，无需打开栖序的设置页。

把你的使用习惯说给 Agent 听

启动栖序后，在你常用的 Agent 里说明想改什么。源码版和打包 EXE 都附有本机控制入口，Agent 可以在一轮对话里读设置、调整多项配置，再告诉你哪些已经生效。

可以这样对 Agent 说

帮我把栖序放在屏幕左下角，缩小一点，打开鼠标穿透。回复尽量简短，晚上 11 点到早上 8 点别主动找我。改好后帮我确认这些设置。

还能定制哪些内容

  • 聊天方式 · 更换模型服务、调整人设与回复偏好
  • 桌面行为 · 调整位置、大小、置顶和穿透，切换本机已有角色
  • 陪伴习惯 · 调整主动频率和勿扰，管理显式记忆与朗读

Agent 会先读取当前版本的能力清单，确认哪些操作可用。

陪伴的分寸，你来定。

栖序把主动陪伴、记忆和桌面工具放进日常对话里。什么时候开口、哪些事值得记住，都可以按自己的习惯调整。

该开口时接话，该安静时等你。

栖序可以主动问候，消息留在同一个会话里，回来就能接着聊。你可以选择主动频率、设定勿扰时段，或者随时暂停。你正在输入或等待回复时，主动问候会让出当前对话。

主动陪伴勿扰示例
  1. 22:40你正在聊天等待当前对话
  2. 23:00进入勿扰暂停主动搭话
  3. 08:00勿扰结束按设定频率重新安排

你决定什么值得记住

告诉栖序「记住，我喜欢先看结论」，以后聊相关话题时就能用上这条偏好。你可以查看、纠正或删除长期记忆。普通聊天记录和你明确保存的记忆各自管理。

聊天里就能顺手办小事

问本机时间、做计算、查网页，或者设一个一次性提醒。需要文件时，可使用你授权的工作区。工作区写入会先生成待确认项，你确认后才提交。

换个模型，保留熟悉的栖序

可配置兼容的模型服务和模型名。人设、会话历史、角色外观和本地朗读独立管理。想换一个模型试试时，已有聊天和角色设置可以继续用。

为 Agent 提供可读、可写、可核验的入口

源码版和 Windows 打包 EXE 随附同一套本机控制 CLI。有本机执行权限的 Agent 可以查询能力和参数，通过同一个入口直接控制正在运行的栖序，并读取结构化结果。接入只要求 Agent 能调用本机命令。

  1. 发现与读取

    列出可管理字段、合法值和生效方式，读取当前配置与修订号。

  2. 预览与应用

    先校验字段并生成变更差异。整批通过才提交，修订冲突时返回最新状态供 Agent 复核。

  3. 回读与恢复

    写入后逐字段比对，把实际结果交还给 Agent。可从快照恢复非秘密配置。

两种 Agent 协作方式

外部 Agent 管理桌宠
它把你的配置意图转成 CLI 请求，通过经过鉴权的 Windows 本机命名管道交给主进程。返回结构化结果，便于处理无效参数、冲突和生效状态。
栖序在对话中调用工具
模型提出调用，应用检查参数、可用工具和权限，再把结果送回模型。工具循环有轮数和时间预算。MCP 能力由用户配置，涉及工作区写入时由用户确认。

系统的四层职责

交互与入口

角色窗负责绘制，管理窗负责聊天和设置，本机 CLI 给外部 Agent 提供管理入口。

主进程与权限

Electron 主进程管理窗口和生命周期，通过受限 IPC 与本机控制通道接收请求，校验后再交给业务模块。

对话与本地状态

组装有限的会话上下文，协调流式回复、取消和主动调度，并分别管理配置、聊天记录和显式记忆。

模型、工具与语音适配

模型服务可切换，工具通过注册表与 MCP 连接器接入，语音交给本机服务按需合成。

一条聊天消息怎么走完一轮

应用先选取最近对话和相关的显式记忆，再发给模型。需要查时间或读网页时，工具结果回到同一轮对话。回复可以边生成边显示，应用记录完成、取消或出错的终态，再按设置处理朗读。

角色与声音

Live2D 桌面角色

分层建模和参数绑定驱动眨眼、视线和待机。透明窗口支持移动、缩放和穿透，隐藏启动后可从管理窗口恢复。

本地语音朗读

按设置将回复送入本机朗读队列。语音模型按需加载，短时间内复用，长时间空闲后卸载以释放资源。

怎么确认它真的生效？

使用隔离配置和打包实窗检查用户路径，再用故障样例验证边界。

Agent 配置
用 CLI 读取实例和修订号，校验一批变更，应用后回读，再检查窗口或下一轮对话。用过期修订号确认并发修改会被拒绝。
对话与主动陪伴
用合成对话检查流式增量、取消与终态，验证下一轮能引用上一轮。用可控时间覆盖勿扰、暂停和请求忙碌时的调度。
桌面与升级恢复
实际启动打包程序，检查隐藏后恢复显示和模型加载。用隔离资料副本演练升级与回退，核对关键数据。
